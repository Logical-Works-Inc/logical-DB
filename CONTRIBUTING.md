# Contributing

Logical-DB is developed by Logical Works. The source is public under the
[Apache License 2.0](LICENSE) so it can be read, used, and audited, but
**external contributions are not accepted at this stage**.

- Pull requests from outside the maintainer team are closed without review.
  Forking is disabled for this repository.
- Issues, comments, and discussions are limited to maintainers.
- Security reports are the one exception: send them privately as described in
  [SECURITY.md](SECURITY.md).

This policy will be revisited when the project opens to outside contributors;
until then no contribution, patch, or suggestion is incorporated, so no
contributor licence terms are offered.
